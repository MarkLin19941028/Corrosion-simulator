# 05: Overpotential-anchored Polarization Curve bands, stacked Depth/Risk plots, standardized palette & unified report overlay legend

**What to build:** Make every uncertainty visualization and kinetics comparison immediately readable across interactive tabs and Technical Reports. Anchor Single Metal Polarization Curve Monte Carlo bands along overpotential ($\eta = E - E_{\text{corr}}$) with dual 50%/90% V-shaped bands around `Net |i_net|` and 2D crosshair error bars at $(E_{\text{corr}}, i_{\text{corr}})$ so the V-cusp never smears into a background wash. Split Single Metal and Galvanic Corrosion Depth and Thickness Loss Risk charts into vertically stacked standalone figures with individual top legends and dual 50%/90% bands, standardize colors and line styles site-wide (`Depth` deep blue solid, `d_crit` dark slate-gray dashed, `Risk` burnt orange dash-dot), and unify both axes into one clear legend on the Technical Report overlay plot.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `MonteCarloPolarizationBand` provides overpotential-anchored net current quantiles (`overpotential_V`, `eta_log10_abs_net_p05`, `p25`, `p75`, `p95`) alongside `Ecorr` and `log10_icorr` quantile summaries (P05, P25, P75, P95), preserving the sharp corrosion cusp at $\eta = 0$ with monotonic quantile ordering (`p05 <= p25 <= median <= p75 <= p95`).
- [ ] Single Metal Polarization Curve charts (both interactive Plotly and Technical Report Matplotlib) render dual overpotential-anchored V-shaped bands labeled `Net |i_net| 50% Band (p25–p75)` and `Net |i_net| 90% Band (p05–p95)` with subtle boundary outlines, plus horizontal ($E_{\text{corr}}$ 90%) and vertical ($i_{\text{corr}}$ 90%) crosshair error bars on the $(E_{\text{corr}}, i_{\text{corr}})$ diamond marker.
- [ ] `MonteCarloKineticsResult` exposes `depth_p25_nm`, `depth_p75_nm`, `risk_p25`, and `risk_p75` arrays alongside existing P05/P50/P95 percentiles for dual-band rendering.
- [ ] Single Metal and Galvanic views render **Corrosion Depth** (top) and **Thickness Loss Risk** (bottom) as two separate vertically stacked standalone Plotly figures—each with its own title and horizontal legend placed directly above its plot area—and display both 50% core and 90% outer bands.
- [ ] Interactive charts and Technical Report figures enforce distinct site-wide styling: `Corrosion Depth` in deep blue solid (`#1f77b4`, `-`) with light-blue dual bands, `d_crit` in dark slate-gray dashed (`#475569`, `--`), `Thickness Loss Risk R(t)` in burnt orange dash-dot (`#d95f02`, `-.`) with light-orange dual bands, and `R(d_crit) = 0.50` in light gray dotted (`#94a3b8`, `:`), with distinct uncoupled vs. coupled line styles in Galvanic comparisons.
- [ ] The Technical Report composite figure's dual-Y-axis Depth & Risk overlay panel uses the exact standardized styles and combines both left-axis (`Depth`, `d_crit`) and right-axis (`Risk R(t)`) entries into a single unified legend with explicit `(left)` and `(right)` labels.
- [ ] Unit and integration tests verify Polarization Curve V-cusp monotonicity, crosshair error bar presence, stacked standalone Depth and Risk figures with top legends, standardized color/dash attributes, and unified dual-axis report legends.
