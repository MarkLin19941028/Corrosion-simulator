# 06: Interactive Streamlit Platform — Single-Metal & Galvanic Analysis Views

**What to build:** An interactive Streamlit web application integrating the database lookup, hybrid ML predictor, polarization solver, bimetallic galvanic mixed-potential solver, time-resolved kinetics, and applicability domain checker. It provides a unified parameter input sidebar (primary **Metal**, optional secondary **Metal** and cathode-to-anode area ratio, **Solution** chemical components and concentrations, pH, operating temperature, **Immersion Time**, **Critical Thickness Threshold ($d_{\text{crit}}$)**, kinetics model selector, and Database vs. ML parameter source toggle) and renders two rich interactive analysis views with Plotly visualizations: **Single Metal Analysis** and **Galvanic Analysis**, complete with uncertainty bands, **Confidence Tier** indicators, **Applicability Domain** warnings, and targeted experimental recommendations.

**Blocked by:** 03: Hybrid Physics-ML Parameter Predictor, Log-Space Uncertainty & Applicability Domain, 04: Area-Weighted Bimetallic Galvanic Mixed-Potential Solver, 05: Time-Resolved Corrosion Kinetics, Time to Threshold & Thickness Loss Risk

**Status:** resolved

- [x] The sidebar allows users to configure any supported **Metal** (`Cu, Co, W, Ru, Ti, Ta, Al, Mo`), optional secondary **Metal** and area ratio, **Solution** composition, pH, temperature, **Immersion Time**, $d_{\text{crit}}$, kinetics model, and parameter source (Database lookup, ML prediction, or manual override).
- [x] The **Single Metal Analysis** view displays interactive Plotly **Polarization Curves** with uncertainty bands, $(E_{\text{corr}}, i_{\text{corr}}, \beta_a, \beta_c) \pm 1\sigma$, **Initial Corrosion Rate ($\text{CR}_0$)**, cumulative **Corrosion Depth** at the target **Immersion Time**, **Time to Threshold**, interactive depth-vs-time and **Thickness Loss Risk**-vs-time trajectories, **Confidence Tier**, and any **Applicability Domain** / data-sufficiency warnings with suggested follow-up experiments.
- [x] The **Galvanic Analysis** view displays interactive overlaid bimetallic **Polarization Curves** with the **Mixed Potential ($E_{\text{galv}}$)** line, **Active Metal** and **Noble Metal** identification, **Galvanic Driving Force Risk**, solved $E_{\text{galv}}$, **Galvanic Current Density ($i_{\text{galv}}$)**, **Acceleration Factor**, accelerated $\text{CR}_0$, **Time to Threshold**, and comparative uncoupled vs. coupled depth and risk trajectories over time.
- [x] Automated integration tests verify that the backing application controller produces complete, schema-valid view payloads and figures for both single-metal and galvanic workflows without runtime errors.
